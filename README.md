# Персональный ассистент: Haystack + Telegram + Pinecone

Домашнее задание к уроку «VPg06. Кейс 2: Персональный ассистент».

Telegram-бот построен на Haystack Agent. Он запоминает, что пишет пользователь, и учитывает это в ответах. Ещё он умеет вызывать четыре инструмента: факт о кошках, картинку собаки, определение породы по фото и погоду.

## Возможности

| Инструмент | Что делает | Источник |
|---|---|---|
| `cat_fact` (CatFactTool) | Случайный факт о кошках, агент переводит его на русский | https://catfact.ninja/fact |
| `dog_image` (DogImageTool) | Ссылка на случайное фото собаки, бот отправляет фото в чат | https://dog.ceo/api/breeds/image/random |
| `dog_image_analyzer` (DogImageAnalyzerTool) | Порода собаки и её краткая история | модель OpenAI с поддержкой изображений |
| `weather` (WeatherTool) | Температура, ощущается как, ветер, описание погоды на русском | Open-Meteo, ключ не нужен |

**Память.** В Pinecone сохраняется только текст сообщений пользователя. Ответы бота, вывод инструментов, команды, пустые и нетекстовые сообщения не сохраняются. У каждого документа есть meta: `user_id`, `chat_id`, `timestamp`, `role="user"`. Перед ответом бот достаёт из Pinecone `top_k` похожих сообщений этого пользователя по косинусному сходству и передаёт их агенту как контекст.

**Команды:** `/start` — приветствие, `/help` — примеры запросов, `/clear` — удалить все сообщения пользователя из Pinecone.

Все обращения к OpenAI идут через `OPENAI_BASE_URL`: генератор агента, эмбеддер и анализ изображений. Если переменная пустая, используется официальный адрес OpenAI.

## Структура

```
hay/
  bot.py            Telegram-бот, команды, логирование
  agent.py          Haystack Agent, системный промпт, запуск с контекстом
  memory.py         Pinecone: фильтр сохранения, запись, retrieval, очистка
  config.py         чтение .env.local и проверка переменных
  tools/
    cat_fact.py     CatFactTool
    dog_image.py    DogImageTool и DogImageAnalyzerTool
    weather.py      WeatherTool (Open-Meteo)
    common.py       логирование вызовов инструментов
tests/              pytest без сети и ключей
screenshots/        сюда положить скриншоты
.env.local.example  образец настроек
```

## Установка и настройка

Нужен Python 3.10 или новее.

### 1. Окружение и зависимости

```bash
python3 -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

### 2. Telegram-бот

1. Откройте в Telegram [@BotFather](https://t.me/BotFather) и отправьте `/newbot`.
2. Задайте имя и username бота.
3. Скопируйте токен в `TELEGRAM_BOT_TOKEN`.

### 3. OpenAI

1. Получите ключ на https://platform.openai.com/api-keys или у своего прокси-провайдера.
2. Запишите ключ в `OPENAI_API_KEY`.
3. Если работаете через прокси, запишите его адрес в `OPENAI_BASE_URL`, например `https://api.proxyapi.ru/openai/v1`. Для официального API оставьте поле пустым.
4. Модель в `OPENAI_MODEL` должна поддерживать вызов инструментов и изображения. Подходит `gpt-4o-mini`.

### 4. Pinecone

1. Зарегистрируйтесь на https://app.pinecone.io и создайте API-ключ в разделе **API Keys**. Запишите его в `PINECONE_API_KEY`.
2. Создайте индекс в разделе **Indexes → Create index**:
   - **Dimension:** `1536` для `text-embedding-3-small`. Для `text-embedding-3-large` нужно `3072`.
   - **Metric:** `cosine`.
   - **Capacity mode:** Serverless, например AWS `us-east-1`.
3. Запишите имя индекса в `PINECONE_INDEX`. `PINECONE_NAMESPACE` можно оставить `default`.

Если индекса с таким именем нет, `PineconeDocumentStore` попробует создать его сам с той же размерностью и метрикой `cosine`. Надёжнее создать индекс вручную.

### 5. Файл .env.local

```bash
cp .env.local.example .env.local
```

Заполните значения. Файл `.env.local` указан в `.gitignore` и не попадает в репозиторий. При старте бот проверяет обязательные переменные и пишет, каких не хватает:

```
Не заданы обязательные переменные окружения: OPENAI_API_KEY, PINECONE_INDEX. ...
```

## Запуск

Из корня проекта:

```bash
python -m hay.bot
```

Логи пишутся в консоль и в `logs/bot.log`. В логах видно сохранение в Pinecone, retrieval с количеством найденных записей и score, вызовы инструментов с аргументами и ошибки.

## Тесты

```bash
pytest -q
```

Тесты не ходят в сеть и не требуют ключей: `requests` и Pinecone замоканы. Они проверяют:

- WeatherTool разбирает ответ Open-Meteo, обрабатывает «город не найден», таймаут и неполные данные;
- фильтр сохранения пропускает только текст пользователя;
- команды, пустые, нетекстовые сообщения и сообщения ботов не сохраняются и не доходят до Pinecone;
- retrieval фильтрует по `user_id`, а `/clear` удаляет документы только этого пользователя;
- конфиг сообщает, каких переменных не хватает.

Тест записи документа с meta требует установленного `haystack-ai`. Без него он пропускается.

## Сценарий ручной проверки

Результаты ниже — **ожидаемое поведение**, а не записанный вывод. Пройдите сценарий сами и сделайте скриншоты.

| Шаг | Что отправить | Что должно произойти |
|---|---|---|
| 1 | `/start` | Приветствие со списком возможностей и команд. |
| 2 | `Меня зовут Иван, я люблю горы` | Бот отвечает. В логе есть строка `Сохранено в Pinecone: user_id=...`. В консоли Pinecone в индексе появляется запись с `role: user`. |
| 3 | `Расскажи факт о кошках` | Факт о кошках на русском. В логе есть `Вызов инструмента cat_fact`. |
| 4 | `Покажи собаку и определи породу` | Фото собаки и текст с породой и её историей. В логе есть вызовы `dog_image` и `dog_image_analyzer`. |
| 5 | `Какая погода в Москве?` | Описание погоды, температура, «ощущается как» и ветер в м/с. В логе есть `Вызов инструмента weather`. |
| 6 | `Как меня зовут и что я люблю?` | Ответ «Иван» и «горы». В логе есть `Retrieval из Pinecone: ... найдено=N`, где N больше нуля. |
| 7 | `/clear`, затем снова шаг 6 | Бот пишет «Память очищена. Удалено записей: N». После этого на вопрос из шага 6 он отвечает, что не знает. |

Что проверить дополнительно:

- В индексе Pinecone нет ответов бота и команд `/start`, `/help`, `/clear`.
- Если отправить фото или стикер, бот ответит, что понимает только текст. В индекс ничего не добавится.
- Если спросить погоду в несуществующем городе, бот скажет, что город не найден, и не упадёт.
